# 데이터 내보내기(Export)

## 데이터 내보내기란?

데이터 내보내기(Export)는 R에서 생성하거나 가공한 데이터를 파일 형태로 저장하는 작업을 의미한다.

데이터를 파일로 저장하면 다음과 같은 작업이 가능하다.

- Excel에서 결과 확인
- 다른 사람과 데이터 공유
- SPSS, SAS, STATA 등 다른 통계 프로그램에서 활용
- 분석 결과 백업
- 다음 작업을 위해 데이터 저장

R에서는 다양한 형식으로 데이터를 저장할 수 있으며, 대표적으로 다음과 같은 파일 형식을 많이 사용한다.

| 파일 형식 | 설명 |
|-----------|------|
| CSV | 가장 많이 사용하는 데이터 파일 |
| TXT | 텍스트 파일 |
| Excel(xlsx) | Microsoft Excel 파일 |
| RDS | 하나의 R 객체 저장 |
| RData | 여러 개의 R 객체 저장 |
| SPSS(.sav) | SPSS 프로그램용 |
| SAS(.sas7bdat) | SAS 프로그램용 |
| STATA(.dta) | STATA 프로그램용 |

---

# 작업 디렉토리(Working Directory)

파일을 저장하기 전에 현재 작업 디렉토리를 확인하는 것이 좋다.

현재 작업 디렉토리는 `getwd()` 함수로 확인할 수 있다.

```r
getwd()
```

### 예시 결과

```text
[1] "C:/Users/JH/Documents"
```

위 경로는 현재 R이 기본적으로 파일을 저장하는 위치이다.

---

# 작업 디렉토리 변경하기

파일을 다른 위치에 저장하려면 작업 디렉토리를 변경하면 된다.

```r
setwd("C:/Users/JH/Desktop")
```

다시 확인해 보자.

```r
getwd()
```

### 예시 결과

```text
[1] "C:/Users/JH/Desktop"
```

이제 저장하는 모든 파일은 Desktop 폴더에 생성된다.

---

# CSV 파일로 저장하기

가장 많이 사용하는 저장 형식은 CSV이다.

CSV는 데이터를 쉼표(,)로 구분하여 저장하는 파일 형식이며, 대부분의 데이터 분석 프로그램에서 지원한다.

CSV 파일은 `write.csv()` 함수를 이용한다.

```r
write.csv(df, "mtcars.csv")
```

실행하면 현재 작업 디렉토리에

```
mtcars.csv
```

파일이 생성된다.

---

# write.csv() 기본 문법

```r
write.csv(
  x,
  file
)
```

| 인수 | 설명 |
|------|------|
| x | 저장할 데이터 |
| file | 저장할 파일명 또는 경로 |

예를 들어 다음과 같이 사용할 수 있다.

```r
write.csv(df, "car.csv")
```

또는

```r
write.csv(iris, "iris.csv")
```

---

# 저장 위치 지정하기

작업 디렉토리가 아닌 다른 위치에도 저장할 수 있다.

```r
write.csv(
  df,
  "C:/Users/JH/Desktop/mtcars.csv"
)
```

또는

```r
write.csv(
  df,
  "D:/Data/mtcars.csv"
)
```

파일 경로와 파일명을 함께 작성하면 원하는 위치에 저장된다.

---

# row.names 옵션

`write.csv()`를 처음 사용하면 행 이름(Row Name)도 함께 저장된다.

예를 들어

```r
write.csv(df, "mtcars.csv")
```

로 저장하면 CSV 파일의 첫 번째 열에 행 이름이 포함된다.

```
"","mpg","disp","hp","gear"
"Mazda RX4",21,160,110,4
```

대부분의 경우 행 이름은 필요하지 않다.

이때는 `row.names = FALSE` 옵션을 사용한다.

```r
write.csv(
  df,
  "mtcars.csv",
  row.names = FALSE
)
```

### 저장 결과

```text
mpg,disp,hp,gear
21.0,160,110,4
21.0,160,110,4
22.8,108,93,4
```

행 이름이 제거되어 깔끔한 CSV 파일이 생성된다.

실무에서는 대부분 `row.names = FALSE`를 함께 사용하는 경우가 많다.

---

# write.csv2()

일부 국가에서는 쉼표 대신 세미콜론(;)을 구분자로 사용한다.

이 경우 `write.csv2()`를 사용할 수 있다.

```r
write.csv2(
  df,
  "mtcars2.csv",
  row.names = FALSE
)
```

예시

```text
mpg;disp;hp;gear
21;160;110;4
21;160;110;4
```

---

# write.csv()와 write.csv2() 차이

| 함수 | 구분자 |
|------|---------|
| `write.csv()` | 쉼표(,) |
| `write.csv2()` | 세미콜론(;) |

대부분의 경우 `write.csv()`를 사용하면 된다.

---

# 텍스트(Text) 파일로 저장하기

CSV 외에도 일반 텍스트 파일로 저장할 수 있다.

텍스트 파일 저장에는 `write.table()` 함수를 사용한다.

```r
write.table(
  df,
  "mtcars.txt"
)
```

현재 작업 폴더에

```
mtcars.txt
```

파일이 생성된다.

---

# write.table() 기본 문법

```r
write.table(
  x,
  file
)
```

| 인수 | 설명 |
|------|------|
| x | 저장할 데이터 |
| file | 파일명 |

예를 들어

```r
write.table(
  iris,
  "iris.txt"
)
```

와 같이 사용할 수 있다.

---

# 구분자 변경하기

기본적으로 `write.table()`은 공백을 구분자로 사용한다.

탭(Tab)으로 구분하려면 `sep = "\t"` 옵션을 사용한다.

```r
write.table(
  df,
  "mtcars_tab.txt",
  sep = "\t",
  row.names = FALSE
)
```

생성된 파일은 다음과 같은 형태가 된다.

```text
mpg    disp    hp    gear
21.0   160     110   4
21.0   160     110   4
22.8   108      93   4
```

탭으로 구분된 텍스트 파일은 Excel에서도 쉽게 열 수 있다.

# 지금까지 배운 함수

| 함수 | 설명 |
|------|------|
| `getwd()` | 현재 작업 디렉토리 확인 |
| `setwd()` | 작업 디렉토리 변경 |
| `write.csv()` | CSV 파일 저장 |
| `write.csv2()` | 세미콜론(;) 형식 CSV 저장 |
| `write.table()` | 텍스트 파일 저장 |

# 정리

이번 Part에서는 데이터를 CSV와 Text 파일로 저장하는 방법을 살펴보았다.

- `getwd()`는 현재 작업 디렉토리를 확인한다.
- `setwd()`는 파일 저장 위치를 변경한다.
- `write.csv()`는 가장 많이 사용하는 CSV 저장 함수이다.
- `row.names = FALSE`를 사용하면 행 이름을 제외하고 저장할 수 있다.
- `write.csv2()`는 세미콜론(;)을 구분자로 사용하는 CSV 파일을 생성한다.
- `write.table()`은 텍스트 파일을 저장할 때 사용하며, `sep` 옵션으로 구분자를 지정할 수 있다.
