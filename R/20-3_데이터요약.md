그룹별 데이터에서 **특정 위치의 값**이나 **관측치의 개수**, **고유값의 개수**를 구하는 함수들을 알아보겠습니다.

이 함수들은 실제 데이터 분석에서 매우 자주 사용됩니다.

---

# 데이터 개수 세기 : n()

`n()` 함수는 현재 그룹에 포함된 **행(Row)의 개수**를 반환합니다.

예를 들어 선수별 기록이 몇 개 존재하는지 확인할 수 있습니다.

```r
data %>%
    group_by(playerID) %>%
    summarise(number_year = n()) %>%
    arrange(desc(number_year))
```

### 결과

```text
# A tibble: 19,182 × 2

playerID  number_year
mcguide01      31
henderi01      29
newsobo01      29
johnto01       28
...
```

위 결과는 각 선수가 데이터에 몇 번 등장하는지를 의미합니다.

즉, 여러 시즌 동안 활동한 선수일수록 `number_year` 값이 커집니다.

---

# 고유값 개수 세기 : n_distinct()

`n_distinct()`는 **중복을 제거한 고유값의 개수**를 계산합니다.

예를 들어 팀별로 활동한 선수 수를 구할 수 있습니다.

```r
data %>%
    group_by(teamID) %>%
    summarise(number_player = n_distinct(playerID)) %>%
    arrange(desc(number_player))
```

### 결과

```text
# A tibble: 149 × 2

teamID number_player
CHN          2051
PHI          2036
SLN          1971
CIN          1912
...
```

`n()`과 `n_distinct()`의 차이는 다음과 같습니다.

| 함수 | 의미 |
|------|------|
| `n()` | 전체 행 개수 |
| `n_distinct()` | 중복을 제외한 고유값 개수 |

---

# 여러 변수로 그룹 지정하기

`group_by()`에는 하나 이상의 변수를 지정할 수 있습니다.

예를 들어 **팀별·연도별 선수 수**를 계산하려면 다음과 같이 작성합니다.

```r
data %>%
    group_by(teamID, yearID) %>%
    summarise(number_player = n_distinct(playerID)) %>%
    arrange(teamID, yearID)
```

### 결과

```text
# A tibble: 2,865 × 3

teamID yearID number_player
ALT      1884          18
ANA      1997          43
ANA      1998          45
...
```

여러 개의 그룹 변수를 지정하면 더 세분화된 분석이 가능합니다.

---

# first()와 last()

그룹 안에서 **첫 번째 값**과 **마지막 값**을 가져오는 함수입니다.

```r
data %>%
    group_by(playerID) %>%
    summarise(
        first_appearance = first(yearID),
        last_appearance = last(yearID)
    )
```

### 결과

```text
playerID first_appearance last_appearance
aardsda01       2015             2004
aaronha01       1966             1976
...
```

하지만 여기서 주의해야 할 점이 있습니다.

`first()`와 `last()`는 **데이터가 입력되어 있는 순서**를 기준으로 값을 가져옵니다.

즉, 가장 오래된 연도나 가장 최근 연도를 의미하는 것은 아닙니다.

---

# 실제 최초와 마지막 연도 구하기

선수의 실제 첫 시즌과 마지막 시즌을 알고 싶다면 `min()`과 `max()`를 사용하는 것이 올바른 방법입니다.

```r
data %>%
    group_by(playerID) %>%
    summarise(
        first_appearance = min(yearID),
        last_appearance = max(yearID)
    )
```

### 결과

```text
playerID first_appearance last_appearance
aardsda01       2004            2015
aaronha01       1954            1976
...
```

분석 목적에 따라 `first()`와 `min()`의 차이를 이해하는 것이 중요합니다.

---

# nth()

`nth()` 함수는 그룹 내에서 **특정 위치의 값**을 가져옵니다.

예를 들어 각 팀의 두 번째 기록 연도를 확인할 수 있습니다.

```r
data %>%
    group_by(teamID) %>%
    summarise(second_game = nth(yearID, 2)) %>%
    arrange(second_game)
```

### 결과

```text
# A tibble: 149 × 2

teamID second_game
BS1        1871
CH1        1871
FW1        1871
BR1        1872
...
```

`nth(x, 2)`는 두 번째 값을,

`nth(x, 5)`는 다섯 번째 값을 반환합니다.

---

# 여러 그룹으로 요약하기

`group_by()`에는 여러 변수를 동시에 사용할 수 있습니다.

예를 들어 연도와 팀을 기준으로 평균 경기 수를 계산할 수 있습니다.

```r
data %>%
    group_by(yearID, teamID) %>%
    summarise(mean_games = mean(G)) %>%
    arrange(desc(teamID))
```

### 결과

```text
# A tibble: 2,865 × 3

yearID teamID mean_games
1884   WSU      19.8
1891   WS9      33.7
1886   WS8      29.9
...
```

복수 그룹을 사용하면 하나의 변수만으로는 확인하기 어려운 세부적인 분석이 가능합니다.

---

# 정리

`summarise()`와 함께 자주 사용하는 함수들을 살펴보았습니다.

| 함수 | 역할 |
|------|------|
| `n()` | 그룹별 행 개수 |
| `n_distinct()` | 그룹별 고유값 개수 |
| `first()` | 첫 번째 값 |
| `last()` | 마지막 값 |
| `nth()` | n번째 값 |
| `group_by(x, y)` | 여러 변수로 그룹화 |

이 함수들은 그룹별 데이터의 구조를 이해하고 원하는 정보를 빠르게 추출할 때 매우 유용하며, 실무에서도 빈번하게 사용됩니다.
