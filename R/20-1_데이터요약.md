데이터 분석에서는 **개별 데이터 하나하나를 보는 것보다 전체적인 특징을 파악하는 과정**이 더 중요한 경우가 많습니다.

예를 들어,

- 평균 매출은 얼마인지
- 부서별 평균 연봉은 얼마인지
- 지역별 고객 수는 몇 명인지
- 연도별 판매량은 어떻게 변했는지

와 같은 정보를 빠르게 확인해야 하는 경우가 많습니다.

R에서는 **dplyr 패키지의 `summarise()`와 `group_by()` 함수**를 이용하면 이러한 작업을 매우 간단하게 수행할 수 있습니다.

이번 글에서는 데이터 요약의 기본 개념과 함께 가장 많이 사용하는 두 함수인 `summarise()`와 `group_by()`의 사용법을 알아보겠습니다.

---

# summarise()

`summarise()`는 데이터의 **요약 통계량(Summary Statistics)** 을 계산하는 함수입니다.

대표적으로 다음과 같은 값을 계산할 수 있습니다.

- 평균(mean)
- 합(sum)
- 중앙값(median)
- 최대값(max)
- 최소값(min)
- 표준편차(sd)
- 개수(n)

기본 문법은 다음과 같습니다.

```r
summarise(data, 새로운변수 = 계산식)
```

예를 들어 득점(R)의 평균을 계산하면 다음과 같습니다.

```r
summarise(data, mean_run = mean(R))
```

### 결과

```text
mean_run
18.7621
```

`mean_run`이라는 새로운 변수에 평균 득점이 저장됩니다.

---

## 여러 개의 요약값 계산하기

한 번에 여러 개의 통계량도 계산할 수 있습니다.

```r
summarise(
    data,
    mean_games = mean(G),
    mean_SH = mean(SH, na.rm = TRUE)
)
```

### 결과

```text
mean_games mean_SH
51.281215 2.279202
```

여기서 사용된

```r
na.rm = TRUE
```

는 결측치(NA)를 제외하고 계산하라는 의미입니다.

결측치가 존재하는 변수는 대부분 이 옵션을 함께 사용하는 것이 좋습니다.

# group_by()

`summarise()`는 전체 데이터의 통계를 계산하지만,

실제 데이터 분석에서는 **그룹별 통계**가 훨씬 많이 사용됩니다.

예를 들어

- 부서별 평균 연봉
- 학과별 평균 학점
- 지역별 평균 매출
- 제품별 판매량

처럼 특정 기준으로 데이터를 묶어서 계산하는 경우입니다.

이때 사용하는 함수가 `group_by()`입니다.

기본 문법은 다음과 같습니다.

```r
data %>%
    group_by(그룹변수) %>%
    summarise(요약값)
```

---

# group_by() 예제

리그(lgID)별 평균 홈런(HR)을 계산해보겠습니다.

```r
data %>%
    group_by(lgID) %>%
    summarise(mean_home_run = mean(HR))
```

### 결과

```text
# A tibble: 7 × 2

lgID mean_home_run
AA      1.01
AL      3.07
FL      1.15
NL      2.75
PL      2.15
UA      0.37
NA      0.29
```

`group_by(lgID)`가 먼저 데이터를 리그별로 나눈 뒤,

각 그룹마다 `summarise()`가 평균 홈런 수를 계산합니다.

즉,

```
전체 데이터
        │
group_by(lgID)
        │
리그별 데이터 생성
        │
summarise()
        │
리그별 평균 계산
```

의 순서로 동작합니다.

---

# 파이프 연산자와 함께 사용하기

`group_by()`와 `summarise()`는 **파이프 연산자 `%>%`** 와 함께 사용하는 것이 일반적입니다.

```r
data %>%
    group_by(lgID) %>%
    summarise(mean_home_run = mean(HR))
```

이 방식은

1. 데이터 선택
2. 그룹 지정
3. 통계 계산

과정을 위에서 아래로 읽을 수 있어 코드의 가독성이 매우 좋아집니다.

---

# group_by()와 ggplot() 함께 사용하기

요약된 데이터를 바로 그래프로 표현하는 것도 가능합니다.

```r
library(ggplot2)

data %>%
    group_by(lgID) %>%
    summarise(mean_home_run = mean(HR)) %>%
    ggplot(aes(x = lgID,
               y = mean_home_run,
               fill = lgID)) +
    geom_bar(stat = "identity") +
    theme_classic() +
    labs(
        title = "Average Home Runs by League",
        x = "League",
        y = "Average Home Runs"
    )
```

위 코드는

- 리그별 평균 홈런 계산
- 결과를 ggplot으로 전달
- 막대그래프 생성

까지 하나의 파이프라인으로 처리합니다.

실무에서도 이러한 형태를 매우 자주 사용합니다.

# 정리

데이터 요약의 핵심 함수인 **`summarise()`와 `group_by()`**를 살펴보았습니다.

정리하면 다음과 같습니다.

| 함수 | 역할 |
|------|------|
| `summarise()` | 요약 통계 계산 |
| `group_by()` | 그룹별 데이터 생성 |
| `%>%` | 여러 작업을 순차적으로 연결 |
| `ggplot()` | 요약 결과 시각화 |

`group_by()`와 `summarise()`는 dplyr에서 가장 많이 사용하는 함수이며, 이후 배우게 될 `filter()`, `mutate()`, `arrange()` 등과 함께 사용하면 더욱 강력한 데이터 분석이 가능합니다.
