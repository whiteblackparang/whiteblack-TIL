# Excel 파일로 저장하기

CSV 파일은 가장 많이 사용하는 형식이지만, 보고서 작성이나 결과 공유를 위해서는 Excel 파일(.xlsx)로 저장하는 경우도 많다.

R에서는 `writexl` 패키지를 이용하여 Excel 파일을 쉽게 생성할 수 있다.

---

# writexl 패키지 설치

처음 사용하는 경우에는 패키지를 설치해야 한다.

```r
install.packages("writexl")
```

패키지를 설치한 후에는 라이브러리를 불러온다.

```r
library(writexl)
```

---

# Excel 파일 저장하기

Excel 파일은 `write_xlsx()` 함수를 이용한다.

```r
write_xlsx(
  df,
  "mtcars.xlsx"
)
```

현재 작업 디렉토리에

```
mtcars.xlsx
```

파일이 생성된다.

---

# write_xlsx() 기본 문법

```r
write_xlsx(
  x,
  path
)
```

| 인수 | 설명 |
|------|------|
| `x` | 저장할 데이터 |
| `path` | 저장할 파일명 또는 경로 |

---

# Excel 저장 예제 1

```r
write_xlsx(
  iris,
  "iris.xlsx"
)
```

---

# Excel 저장 예제 2

```r
student <- data.frame(

  name = c("Kim", "Lee", "Park"),

  score = c(90, 85, 95)

)

write_xlsx(
  student,
  "student.xlsx"
)
```

Excel 파일을 열면 다음과 같이 저장된다.

| name | score |
|------|------:|
| Kim | 90 |
| Lee | 85 |
| Park | 95 |

---

# 원하는 위치에 저장하기

파일 경로를 함께 작성하면 원하는 위치에 저장할 수 있다.

```r
write_xlsx(
  df,
  "C:/Users/JH/Desktop/mtcars.xlsx"
)
```

---

# 여러 개의 Sheet 저장하기

하나의 Excel 파일에 여러 개의 시트를 저장할 수도 있다.

```r
write_xlsx(

  list(

    mtcars = mtcars,

    iris = iris

  ),

  "example.xlsx"

)
```

생성된 Excel 파일에는

- mtcars
- iris

두 개의 시트가 생성된다.

---

# 예제 3. 여러 Sheet 저장

```r
write_xlsx(

  list(

    student = student,

    car = df

  ),

  "report.xlsx"

)
```

# RDS 파일이란?

RDS 파일은 **하나의 R 객체(Object)**를 저장하는 파일 형식이다.

CSV와 달리 데이터의 자료형과 구조를 그대로 유지할 수 있다는 장점이 있다.

예를 들어

- 데이터 프레임
- 리스트
- 행렬
- 벡터

모두 그대로 저장할 수 있다.

---

# saveRDS()

R 객체 하나를 저장하려면 `saveRDS()`를 사용한다.

```r
saveRDS(

  df,

  "mtcars.rds"

)
```

현재 작업 폴더에

```
mtcars.rds
```

파일이 생성된다.

---

# saveRDS() 기본 문법

```r
saveRDS(

  object,

  file

)
```

| 인수 | 설명 |
|------|------|
| `object` | 저장할 객체 |
| `file` | 파일명 |

---

# RDS 파일 읽기

저장한 RDS 파일은 `readRDS()` 함수로 읽는다.

```r
new_df <- readRDS(

  "mtcars.rds"

)
```

확인해 보자.

```r
head(new_df)
```

### 결과

```text
                   mpg disp hp gear
Mazda RX4         21.0 160 110    4
Mazda RX4 Wag     21.0 160 110    4
Datsun 710        22.8 108  93    4
Hornet 4 Drive    21.4 258 110    3
Hornet Sportabout 18.7 360 175    3
Valiant           18.1 225 105    3
```

원래 데이터와 동일한 구조를 유지한다.

---

```r
saveRDS(

```

```r
iris2 <- readRDS(
```

# RData 파일이란?

`.RData` 파일은 여러 개의 R 객체를 한 번에 저장하는 파일 형식이다.

예를 들어

- 데이터 프레임
- 벡터
- 리스트
- 함수

등 여러 객체를 하나의 파일에 저장할 수 있다.

---

# save()

`.RData` 파일을 저장하려면 `save()` 함수를 사용한다.

```r
save(

  df,

  file = "mtcars.RData"

)
```

---

# 여러 객체 저장하기

여러 개의 객체를 동시에 저장할 수도 있다.

```r
score <- c(90, 80, 95)

student <- data.frame(

  name = c("Kim", "Lee"),

  score = c(90, 85)

)

save(

  df,

  score,

  student,

  file = "project.RData"

)
```

---

# load()

저장한 `.RData` 파일은 `load()` 함수로 불러온다.

```r
load(

  "project.RData"

)
```

불러오기가 완료되면

- df
- score
- student

객체가 작업 공간에 생성된다.

---

# saveRDS()와 save() 차이

| 함수 | 특징 |
|------|------|
| `saveRDS()` | 객체 1개 저장 |
| `save()` | 여러 객체 저장 |

`saveRDS()`는 하나의 객체를 저장할 때 사용하며,

`save()`는 프로젝트 전체를 저장할 때 자주 사용된다.

---

# 예제 7. 프로젝트 저장

```r
result <- lm(

  mpg ~ hp,

  data = mtcars

)

save(

  mtcars,

  result,

  file = "analysis.RData"

)
```

---

# 예제 8. 프로젝트 불러오기

```r
load(

  "analysis.RData"
)
```

이전 작업이 그대로 복원된다.

---

# 지금까지 배운 함수

| 함수 | 설명 |
|------|------|
| `write_xlsx()` | Excel 저장 |
| `saveRDS()` | R 객체 하나 저장 |
| `readRDS()` | RDS 파일 읽기 |
| `save()` | 여러 객체 저장 |
| `load()` | RData 불러오기 |

---

# 정리

이번 Part에서는 Excel과 R 전용 파일 형식으로 데이터를 저장하는 방법을 살펴보았다.

- `write_xlsx()`는 Excel 파일을 생성한다.
- 하나의 Excel 파일에 여러 개의 시트를 저장할 수도 있다.
- `saveRDS()`는 하나의 R 객체를 저장한다.
- `readRDS()`는 저장된 RDS 파일을 불러온다.
- `save()`는 여러 개의 객체를 하나의 `.RData` 파일로 저장한다.
- `load()`는 `.RData` 파일을 불러와 작업 공간을 복원한다.
