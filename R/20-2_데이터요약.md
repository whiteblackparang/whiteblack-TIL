`summarise()`에서 자주 사용하는 다양한 요약 함수를 알아보겠습니다.

평균뿐만 아니라 중앙값, 합계, 표준편차, 최소·최대값 등은 데이터 분석에서 가장 많이 사용하는 통계량입니다.

---

# summarise()에서 사용할 수 있는 주요 함수

`summarise()`는 거의 모든 통계 함수를 사용할 수 있습니다.

대표적인 함수는 다음과 같습니다.

| 목적 | 함수 |
|------|------|
| 평균 | `mean()` |
| 중앙값 | `median()` |
| 합계 | `sum()` |
| 표준편차 | `sd()` |
| 사분위 범위 | `IQR()` |
| 최소값 | `min()` |
| 최대값 | `max()` |
| 사분위수 | `quantile()` |

필요에 따라 원하는 함수를 자유롭게 조합하여 사용할 수 있습니다.

---

# 평균(mean)

가장 많이 사용하는 통계량은 평균입니다.

연도별 평균 경기 수를 계산해 보겠습니다.

```r
ex1 <- data %>%
    group_by(yearID) %>%
    summarise(mean_game_year = mean(G))

head(ex1)
```

### 결과

```text
# A tibble: 6 × 2

yearID mean_game_year
1871      20.0
1872      21.1
1873      28.8
1874      34.1
1875      28.7
1876      37.9
```

각 연도마다 선수들의 평균 경기 수가 계산되었습니다.

---

# 평균 데이터 시각화

요약된 데이터는 바로 그래프로 표현할 수도 있습니다.

```r
ggplot(ex1,
       aes(x = yearID,
           y = mean_game_year)) +
    geom_line() +
    theme_classic() +
    labs(
        title = "Average games played from 1871 to 2016",
        x = "Year",
        y = "Average Games"
    )
```

위 코드는 연도별 평균 경기 수의 변화를 선 그래프로 보여줍니다.

요약 데이터를 그래프로 표현하면 시간에 따른 변화나 추세를 쉽게 파악할 수 있습니다.

---

# 중앙값(median)

중앙값(Median)은 데이터를 크기순으로 정렬했을 때 가운데 위치한 값입니다.

평균은 이상치(Outlier)의 영향을 받을 수 있지만,

중앙값은 이상치의 영향을 상대적으로 적게 받는다는 장점이 있습니다.

다음은 리그별 타석(AB)의 중앙값을 계산하는 예입니다.

```r
data %>%
    group_by(lgID) %>%
    summarise(
        median_at_bat = median(AB),
        median_no_zero = median(AB[AB > 0])
    )
```

### 결과

```text
# A tibble: 7 × 3

lgID median_at_bat median_no_zero
AA      126            128
AL       37             87
FL       84.5           88
NL       53             64
PL      218            218
UA       36             36
NA       95             95
```

여기서는

```r
AB[AB > 0]
```

을 사용하여 **0인 값을 제외한 중앙값**도 함께 계산했습니다.

데이터에 0이 많이 포함되어 있을 경우 분석 결과가 달라질 수 있으므로 이러한 비교도 자주 수행합니다.

---

# 합계(sum)

`sum()` 함수는 그룹별 합계를 계산합니다.

리그별 전체 홈런 수를 계산해 보겠습니다.

```r
data %>%
    group_by(lgID) %>%
    summarise(sum_home_run = sum(HR))
```

### 결과

```text
# A tibble: 7 × 2

lgID sum_home_run
AA      1907
AL    146908
FL       545
NL    145386
PL       320
UA       125
NA       211
```

각 리그에서 기록된 전체 홈런 개수를 확인할 수 있습니다.

---

# 표준편차(sd)

표준편차(Standard Deviation)는 데이터가 평균으로부터 얼마나 퍼져 있는지를 나타내는 지표입니다.

값이 클수록 데이터의 변동성이 크다는 의미입니다.

```r
data %>%
    group_by(teamID) %>%
    summarise(sd_home_run = sd(HR))
```

### 결과

```text
# A tibble: 149 × 2

teamID sd_home_run
ALT       0.323
ANA       8.140
ARI       7.310
ATL       7.680
...
```

팀마다 홈런 기록의 변동성이 서로 다르다는 것을 확인할 수 있습니다.

---

# 최소값과 최대값

`min()`과 `max()` 함수는 가장 작은 값과 가장 큰 값을 계산합니다.

다음은 선수별 최소 경기 수와 최대 경기 수를 계산하는 예입니다.

```r
data %>%
    group_by(playerID) %>%
    summarise(
        min_G = min(G),
        max_G = max(G)
    )
```

### 결과

```text
# A tibble: 19,182 × 3

playerID min_G max_G
aardsda01    1    73
aaronha01   85   161
aaronto01    8   141
...
```

선수마다 시즌 동안 출전한 최소 경기 수와 최대 경기 수를 한 번에 확인할 수 있습니다.

---

# 정리

`summarise()`에서 자주 사용하는 주요 통계 함수를 살펴보았습니다.

| 함수 | 역할 |
|------|------|
| `mean()` | 평균 |
| `median()` | 중앙값 |
| `sum()` | 합계 |
| `sd()` | 표준편차 |
| `min()` | 최소값 |
| `max()` | 최대값 |
| `IQR()` | 사분위 범위 |
| `quantile()` | 사분위수 |

이 함수들은 `group_by()`와 함께 사용하면 그룹별 통계를 손쉽게 계산할 수 있으며, 데이터 분석 과정에서 가장 기본적이면서도 자주 활용되는 기능입니다.
