# 상관계수 행렬(Correlation Matrix)

두 변수 사이의 상관관계를 계산하였다.

하지만 실제 데이터 분석에서는 변수가 수십 개 이상인 경우가 많다.

이처럼 여러 변수 간의 상관관계를 한 번에 확인하기 위해 사용하는 것이 **상관계수 행렬(Correlation Matrix)** 이다.

상관계수 행렬은 모든 변수의 상관계수를 표 형태로 나타낸 행렬이다.

예를 들어 다음과 같은 변수들이 있다고 가정해보자.

- 식비(wfood)
- 연료비(wfuel)
- 의류비(wcloth)
- 교통비(wtrans)
- 소득(log_income)

상관계수 행렬을 이용하면 모든 변수 쌍의 상관관계를 한 번에 확인할 수 있다.

---

# cor() 함수로 상관계수 행렬 만들기

상관계수 행렬도 `cor()` 함수로 쉽게 계산할 수 있다.

```r
cor(data3[, 1:9])
```

여기서는 별도의 x, y를 지정하지 않고 데이터 프레임을 전달하였다.

그러면 모든 변수에 대한 상관계수를 계산한다.

---

# factor 변수는 제외해야 한다

상관분석은 수치형 변수(Numeric)를 대상으로 수행된다.

따라서 factor(범주형) 변수는 제외해야 한다.

예를 들어 `children_fac` 변수는 factor형이므로 분석 대상에서 제외한다.

```r
data3[, 1:9]
```

앞의 9개 변수만 선택하여 상관계수를 계산한다.

---

# 소수점 자리수 조정

상관계수는 소수점이 길게 출력되는 경우가 많다.

읽기 쉽도록 `round()` 함수를 함께 사용하는 것이 일반적이다.

```r
round(
  cor(data3[, 1:9]),
  2
)
```

### 코드 설명

```r
cor(data3[, 1:9])
```

- 상관계수 계산

```r
round(..., 2)
```

- 소수 둘째 자리까지 반올림

---

# 행렬의 절반만 보기

상관계수 행렬은 대칭 행렬이다.

예를 들어

```text
A와 B의 상관계수

=

B와 A의 상관계수
```

따라서 같은 값이 두 번 출력된다.

이를 줄이기 위해 `as.dist()` 함수를 사용할 수 있다.

```r
mat_1 <-

  as.dist(

    round(

      cor(data3[, 1:9]),

      2

    )

  )

mat_1
```

# 유의성 검정(P-value)

상관계수가 있다고 해서 모두 의미 있는 관계는 아니다.

우연히 나타난 상관관계일 수도 있기 때문이다.

따라서 상관분석에서는 **유의성 검정(Significance Test)** 을 함께 수행하는 경우가 많다.

이를 위해 `Hmisc` 패키지의 `rcorr()` 함수를 사용한다.

---

# Hmisc 패키지 설치

```r
install.packages("Hmisc")
```

설치가 끝났다면 패키지를 불러온다.

```r
library(Hmisc)
```

---

# rcorr() 사용하기

`rcorr()` 함수는 데이터를 행렬(Matrix) 형태로 전달해야 한다.

먼저 데이터를 행렬로 변환한다.

```r
data_rcorr <-

  as.matrix(

    data3[,1:9]

  )
```

---

# 상관계수와 p-value 계산

```r
mat_2 <-

  rcorr(data_rcorr)
```

또는 다음처럼 한 줄로 작성할 수도 있다.

```r
mat_2 <-

  rcorr(

    as.matrix(data3[,1:9])

  )
```

---

# rcorr()의 반환값

`rcorr()`는 리스트(List)를 반환한다.

```r
str(mat_2)
```

다음과 같은 세 개의 요소를 포함한다.

| 요소 | 설명 |
|------|------|
| r | 상관계수 행렬 |
| n | 관측치 개수 |
| P | p-value 행렬 |

---

# 상관계수 확인

```r
mat_2$r
```

상관계수 행렬을 반환한다.

---

# 관측치 개수 확인

```r
mat_2$n
```

각 변수쌍에 사용된 관측치 수를 반환한다.

---

# p-value 확인

```r
p_value <-

  round(

    mat_2[["P"]],

    3

  )

p_value
```

# p-value 해석

일반적으로 다음 기준을 사용한다.

| p-value | 해석 |
|----------|------|
| < 0.001 | 매우 유의함 |
| < 0.01 | 매우 유의함 |
| < 0.05 | 유의함 |
| ≥ 0.05 | 유의하지 않음 |

예를 들어

```text
0.000
```

이라면 두 변수의 상관관계는 통계적으로 매우 유의하다고 해석한다.

반면

```text
0.365
```

처럼 0.05보다 크다면 유의한 상관관계가 있다고 보기 어렵다.

---

# 상관계수와 p-value의 차이

| 항목 | 의미 |
|------|------|
| 상관계수(r) | 관계의 방향과 강도 |
| p-value | 관계의 통계적 유의성 |

즉,

- 상관계수는 얼마나 관련이 있는지,
- p-value는 그 관계를 신뢰할 수 있는지를 의미한다.

---

# 자주 사용하는 함수 정리

| 함수 | 설명 |
|------|------|
| `cor()` | 상관계수 계산 |
| `round()` | 반올림 |
| `as.dist()` | 행렬 일부만 출력 |
| `as.matrix()` | 행렬로 변환 |
| `rcorr()` | 상관계수와 p-value 계산 |
| `str()` | 객체 구조 확인 |

---

# 정리

상관계수 행렬은 여러 변수 간의 상관관계를 한 번에 분석할 수 있는 방법이다.

- `cor()` 함수는 모든 변수의 상관계수를 계산한다.
- `round()`를 이용하면 결과를 보기 쉽게 정리할 수 있다.
- `as.dist()`는 중복되는 행렬의 절반만 출력한다.
- `rcorr()`는 상관계수뿐 아니라 p-value와 관측치 개수도 함께 제공한다.
- p-value를 이용하면 상관관계가 통계적으로 의미 있는지 판단할 수 있다.
