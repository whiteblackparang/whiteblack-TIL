# ggpairs()를 이용한 다변량 상관분석

`ggcorr()`는 변수 간의 상관계수를 한눈에 확인하기에는 매우 편리하지만, 실제 데이터의 분포나 변수 간의 관계까지 확인하기에는 한계가 있다.

이럴 때 사용하는 함수가 **`ggpairs()`**이다.

`ggpairs()`는 여러 변수에 대해 다음 정보를 하나의 행렬(Matrix) 형태로 동시에 보여준다.

- 변수별 분포
- 변수 간 산점도(Scatter Plot)
- 변수 간 상관계수(Correlation)
- 그룹별 비교

탐색적 데이터 분석(EDA)에서 매우 자주 사용하는 시각화 함수 중 하나이다.

---

# GGally 패키지

`ggpairs()`는 **GGally** 패키지에서 제공한다.

먼저 패키지를 불러온다.

```r
library(GGally)
library(ggplot2)
```

---

# 기본 문법

```r
ggpairs(
  data,
  columns = 1:ncol(data),
  title = NULL,
  upper = list(continuous = "cor"),
  lower = list(continuous = "smooth"),
  mapping = NULL
)
```

---

# 주요 인수

| 인수 | 설명 |
|------|------|
| `data` | 데이터 프레임 |
| `columns` | 사용할 변수 선택 |
| `title` | 그래프 제목 |
| `upper` | 대각선 위 영역 설정 |
| `lower` | 대각선 아래 영역 설정 |
| `mapping` | 색상 등 그룹 지정 |

---

# 기본 예제

다음 예제에서는 네 개의 변수를 이용하여 다변량 상관분석을 수행한다.

```r
library(GGally)
library(ggplot2)

ggpairs(
  data3,
  columns = c(
    "log_totexp",
    "log_income",
    "age",
    "wtrans"
  )
)
```

---

# 결과

행렬(Matrix) 형태의 그래프가 생성된다.

각 영역은 서로 다른 정보를 제공한다.

- 대각선 : 변수의 분포
- 대각선 위 : 상관계수
- 대각선 아래 : 산점도

한 개의 그래프만으로 변수 간 관계를 전체적으로 파악할 수 있다.

---

# 변수 선택하기

모든 변수를 사용할 필요는 없다.

관심 있는 변수만 선택하여 분석할 수 있다.

```r
ggpairs(
  data3,
  columns = c(
    "log_income",
    "log_totexp",
    "age"
  )
)
```

---

# 그래프 제목 추가

```r
ggpairs(
  data3,
  columns = c(
    "log_totexp",
    "log_income",
    "age",
    "wtrans"
  ),
  title = "Correlation Analysis"
)
```

---

# 상단에 상관계수 표시

대각선 위에는 상관계수를 표시하도록 설정할 수 있다.

```r
ggpairs(
  data3,
  columns = c(
    "log_totexp",
    "log_income",
    "age",
    "wtrans"
  ),

  upper = list(
    continuous = wrap(
      "cor",
      size = 3
    )
  )
)
```

---

# 코드 설명

```r
upper = list(
  continuous = wrap(
    "cor",
    size = 3
  )
)
```

- `upper` : 대각선 위 영역 설정
- `"cor"` : 상관계수 출력
- `size = 3` : 글자 크기

---

# 하단에 추세선 추가

대각선 아래에는 산점도와 추세선을 표시할 수 있다.

```r
ggpairs(
  data3,

  columns = c(
    "log_totexp",
    "log_income",
    "age",
    "wtrans"
  ),

  lower = list(
    continuous = wrap(
      "smooth",
      alpha = 0.3,
      size = 0.1
    )
  )
)
```

---

# 코드 설명

```r
lower = list(
  continuous = wrap(
    "smooth",
    alpha = 0.3,
    size = 0.1
  )
)
```

- `"smooth"` : 추세선 추가
- `alpha` : 투명도
- `size` : 선 굵기

---

# 그룹별 색상 지정

특정 변수에 따라 색상을 다르게 표시할 수도 있다.

예를 들어 `children_fac` 변수로 그룹을 구분하면 다음과 같다.

```r
ggpairs(
  data3,

  columns = c(
    "log_totexp",
    "log_income",
    "age",
    "wtrans"
  ),

  upper = list(
    continuous = wrap(
      "cor",
      size = 3
    )
  ),

  lower = list(
    continuous = wrap(
      "smooth",
      alpha = 0.3,
      size = 0.1
    )
  ),

  mapping = aes(
    color = children_fac
  )
)
```

---

# 결과

자녀 유무(`children_fac`)에 따라

- 산점도
- 추세선
- 분포

가 서로 다른 색상으로 표시된다.

그룹별 특성을 비교하기 쉽다.

---

# 상단만 그룹별 표시

상단의 상관계수만 그룹별로 표시하고 싶다면 `mapping`을 `upper` 안으로 이동하면 된다.

```r
ggpairs(

  data3,

  columns = c(
    "log_totexp",
    "log_income",
    "age",
    "wtrans"
  ),

  upper = list(

    continuous = wrap(
      "cor",
      size = 3
    ),

    mapping = aes(
      color = children_fac
    )

  ),

  lower = list(

    continuous = wrap(
      "smooth",
      alpha = 0.3,
      size = 0.1
    )

  )

)
```

---

# 전체 mapping과 upper mapping의 차이

| 위치 | 적용 대상 |
|------|-----------|
| `mapping = aes(...)` | 그래프 전체 |
| `upper = list(mapping = aes(...))` | 상단 상관계수만 |

필요에 따라 원하는 영역에만 그룹 정보를 적용할 수 있다.

---

# ggpairs()의 장점

`ggpairs()`는 여러 개의 그래프를 각각 그릴 필요 없이 하나의 그래프로 다양한 정보를 제공한다.

다음 내용을 동시에 확인할 수 있다.

- 변수별 분포
- 변수 간 산점도
- 선형 관계
- 상관계수
- 그룹별 비교

탐색적 데이터 분석(EDA) 단계에서 매우 유용하게 활용된다.

---

# 정리

`ggpairs()`는 여러 변수 간의 관계를 하나의 행렬 형태로 시각화하는 함수이다.

- `GGally` 패키지에서 제공한다.
- 변수의 분포와 산점도를 동시에 확인할 수 있다.
- 상관계수를 함께 표시할 수 있다.
- 추세선을 추가하여 변수 간 관계를 쉽게 파악할 수 있다.
- `mapping`을 이용하면 그룹별 비교도 가능하다.
- 탐색적 데이터 분석(EDA)에서 매우 자주 사용되는 시각화 함수이다.
