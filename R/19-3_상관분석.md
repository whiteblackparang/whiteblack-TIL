# 상관계수 행렬 시각화

상관계수 행렬은 여러 변수 간의 관계를 수치로 확인할 수 있다는 장점이 있지만, 변수의 개수가 많아질수록 해석이 어려워진다.

이럴 때 **Heatmap(열 지도)** 형태로 시각화하면 변수 간의 상관관계를 훨씬 직관적으로 파악할 수 있다.

R에서는 **GGally 패키지**의 `ggcorr()` 함수를 이용하여 상관계수 행렬을 손쉽게 시각화할 수 있다.

---

# GGally 패키지

`GGally`는 `ggplot2`를 기반으로 만들어진 확장 패키지이다.

상관분석뿐 아니라 다양한 통계 그래프를 쉽게 생성할 수 있는 여러 함수를 제공한다.

먼저 패키지를 설치한다.

```r
install.packages("GGally")
```

설치가 완료되면 라이브러리를 불러온다.

```r
library(GGally)
```

---

# ggcorr() 함수

기본 문법은 다음과 같다.

```r
ggcorr(
  data,
  method = c("pairwise", "pearson"),
  nbreaks = NULL,
  digits = 2,
  low = "#3B9AB2",
  mid = "#EEEEEE",
  high = "#F21A00",
  geom = "tile",
  label = FALSE
)
```

---

# 주요 인수

| 인수 | 설명 |
|------|------|
| `data` | 데이터 프레임 |
| `method` | 상관계수 계산 방법 |
| `nbreaks` | 색상 구간 개수 |
| `digits` | 소수점 자리수 |
| `low` | 음의 상관 색상 |
| `mid` | 중간 색상 |
| `high` | 양의 상관 색상 |
| `geom` | 셀 모양 |
| `label` | 상관계수 표시 여부 |

---

# 기본 Heatmap 그리기

가장 기본적인 사용 방법은 데이터 프레임만 전달하는 것이다.

```r
library(GGally)

ggcorr(data3)
```

---

# 결과

Heatmap이 생성되며 각 변수 사이의 상관관계를 색상으로 표현한다.

일반적으로

- 파란색 계열 → 음의 상관관계
- 흰색 → 상관관계가 거의 없음
- 빨간색 계열 → 양의 상관관계

를 의미한다.

색이 진할수록 상관관계의 절대값이 크다.

---

# 코드 설명

```r
ggcorr(data3)
```

- 데이터 프레임 전체를 이용하여 상관계수를 계산한다.
- 수치형 변수만 자동으로 선택된다.
- factor 변수는 자동으로 제외된다.

---

# 색상 구간 변경하기

색상을 원하는 형태로 변경할 수도 있다.

```r
ggcorr(
  data3,
  nbreaks = 6,
  low = "steelblue",
  mid = "white",
  high = "darkred"
)
```

---

# 코드 설명

```r
nbreaks = 6
```

색상을 6개의 구간으로 나눈다.

```r
low = "steelblue"
```

음의 상관관계 색상을 지정한다.

```r
mid = "white"
```

상관계수가 0에 가까운 경우의 색상이다.

```r
high = "darkred"
```

양의 상관관계를 표현하는 색상이다.

---

# 셀 모양 변경하기

기본 Heatmap은 사각형(Tile)으로 표시된다.

원(Circle) 형태로 변경할 수도 있다.

```r
ggcorr(
  data3,
  nbreaks = 6,
  low = "steelblue",
  mid = "white",
  high = "darkred",
  geom = "circle"
)
```

---

# 결과

각 셀이 원으로 표시된다.

원의 크기는 상관계수의 절대값에 비례한다.

즉,

- 큰 원 → 강한 상관관계
- 작은 원 → 약한 상관관계

를 의미한다.

---

# 상관계수 표시하기

Heatmap 안에 상관계수를 함께 표시할 수도 있다.

```r
ggcorr(
  data3,
  nbreaks = 6,
  label = TRUE,
  label_size = 3,
  color = "grey50"
)
```

---

# 코드 설명

```r
label = TRUE
```

상관계수 값을 표시한다.

```r
label_size = 3
```

숫자의 크기를 지정한다.

```r
color = "grey50"
```

상관계수 글자의 색상을 지정한다.

---

# 소수점 자리수 변경

표시되는 상관계수의 자리수도 변경할 수 있다.

```r
ggcorr(
  data3,
  digits = 3,
  label = TRUE
)
```

---

# 코드 설명

```r
digits = 3
```

상관계수를 소수 셋째 자리까지 표시한다.

---

# Spearman 상관계수 시각화

기본값은 Pearson 상관계수이다.

Spearman 상관계수를 사용하려면 다음과 같이 작성한다.

```r
ggcorr(
  data3,
  method = c("pairwise", "spearman")
)
```

---

# Pearson와 Spearman 비교

| 방법 | 특징 |
|------|------|
| Pearson | 선형 관계 분석 |
| Spearman | 순위 기반 분석 |

데이터에 이상치가 많거나 정규성을 만족하지 않는 경우에는 Spearman 방법이 더 적합하다.

# Heatmap을 사용하는 이유

Heatmap은 많은 변수의 상관관계를 한눈에 확인할 수 있다는 장점이 있다.

특히

- 강한 양의 상관관계
- 강한 음의 상관관계
- 거의 관계가 없는 변수

를 빠르게 찾을 수 있어 탐색적 데이터 분석(EDA)에서 자주 사용된다.

---

# 자주 사용하는 함수 정리

| 함수 | 설명 |
|------|------|
| `ggcorr()` | 상관계수 Heatmap 생성 |
| `install.packages()` | 패키지 설치 |
| `library()` | 패키지 불러오기 |

---

# 정리

`ggcorr()` 함수는 상관계수 행렬을 Heatmap 형태로 시각화하는 함수이다.

- `GGally` 패키지에서 제공한다.
- `ggcorr()`만으로 상관계수 행렬을 쉽게 시각화할 수 있다.
- `geom`을 이용해 사각형 또는 원 형태로 표현할 수 있다.
- `label = TRUE`를 사용하면 상관계수를 함께 표시할 수 있다.
- `low`, `mid`, `high`를 이용하면 색상을 자유롭게 변경할 수 있다.
- `method`를 변경하여 Pearson 또는 Spearman 상관계수를 시각화할 수 있다.
