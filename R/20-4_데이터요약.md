`group_by()`와 함께 자주 사용하는 `filter()`와 `ungroup()` 함수의 활용법을 살펴보겠습니다.

데이터를 그룹화한 뒤 필요한 데이터만 선택하거나, 그룹을 해제하여 새로운 계산을 수행하는 과정은 실제 데이터 분석에서 매우 자주 사용됩니다.

---

# filter()와 함께 사용하기

요약 통계를 계산하기 전에 원하는 데이터만 선택하면 더욱 의미 있는 분석이 가능합니다.

예를 들어 1980년 이후의 데이터만 사용하여 연도별 평균 경기 수를 계산해 보겠습니다.

```r
data %>%
    filter(yearID > 1980) %>%
    group_by(yearID) %>%
    summarise(mean_game_year = mean(G))
```

### 결과

```text
# A tibble: 37 × 2

yearID mean_game_year
1981        40.0
1982        56.6
1983        56.1
1984        58.1
1985        57.2
...
```

위 코드의 실행 순서는 다음과 같습니다.

1. 1980년 이후의 데이터만 선택
2. 연도별로 그룹 생성
3. 각 연도의 평균 경기 수 계산

필요한 데이터만 먼저 추출한 뒤 요약하면 분석 속도와 결과의 정확성을 높일 수 있습니다.

---

# ungroup()

`group_by()`를 사용하면 데이터는 계속 그룹 상태를 유지합니다.

이 상태에서 새로운 `summarise()`를 수행하면 그룹별 계산이 계속 적용됩니다.

전체 데이터를 대상으로 다시 계산하고 싶다면 `ungroup()`을 사용하여 그룹을 해제해야 합니다.

기본 문법은 다음과 같습니다.

```r
data %>%
    group_by(변수) %>%
    summarise(...) %>%
    ungroup()
```

---

# ungroup() 사용 예제

홈런(HR)을 한 번이라도 기록한 선수만 선택한 뒤,

선수별 경기당 평균 홈런 수를 계산하고,

마지막에는 모든 선수의 평균을 계산해 보겠습니다.

```r
data %>%
    filter(HR > 0) %>%
    group_by(playerID) %>%
    summarise(
        average_HR_game = sum(HR) / sum(G)
    ) %>%
    ungroup() %>%
    summarise(
        total_average_homerun = mean(average_HR_game)
    )
```

### 결과

```text
# A tibble: 1 × 1

total_average_homerun
0.0624
```

여기서 `ungroup()`이 없다면 마지막 `summarise()`도 그룹별 계산으로 처리될 수 있습니다.

따라서 **새로운 집계를 수행하기 전에는 그룹을 해제하는 습관**을 갖는 것이 좋습니다.

---

# group_by()와 ungroup()의 흐름

데이터 분석 과정은 일반적으로 다음과 같은 순서로 진행됩니다.

```text
원본 데이터
      │
filter()
      │
group_by()
      │
summarise()
      │
ungroup()
      │
새로운 계산 수행
```

이와 같은 파이프라인을 이해하면 대부분의 데이터 집계 작업을 손쉽게 수행할 수 있습니다.

---

# 자주 사용하는 요약 함수

`summarise()`에서 가장 많이 사용하는 함수들을 정리하면 다음과 같습니다.

| 함수 | 설명 |
|------|------|
| `mean()` | 평균 |
| `median()` | 중앙값 |
| `sum()` | 합계 |
| `sd()` | 표준편차 |
| `min()` | 최소값 |
| `max()` | 최대값 |
| `quantile()` | 사분위수 |
| `first()` | 첫 번째 값 |
| `last()` | 마지막 값 |
| `nth()` | n번째 값 |
| `n()` | 행 개수 |
| `n_distinct()` | 고유값 개수 |

---

# group_by() 핵심 문법

그룹을 하나만 지정할 수도 있고, 여러 개를 동시에 지정할 수도 있습니다.

```r
# 하나의 그룹

group_by(df, teamID)

# 두 개 이상의 그룹

group_by(df, teamID, yearID)

# 그룹 해제

ungroup(df)
```

복수의 그룹을 지정하면 더욱 세분화된 통계를 계산할 수 있으며, `summarise()`, `mutate()`, `filter()`, `arrange()` 등과 함께 사용할 때 더욱 강력한 기능을 제공합니다.

# 마무리

`filter()`와 `ungroup()`을 이용한 데이터 요약 과정을 살펴보았습니다.

지금까지 학습한 내용을 정리하면 다음과 같습니다.

- `summarise()`는 요약 통계를 계산하는 함수입니다.
- `group_by()`는 데이터를 그룹별로 나누어 계산합니다.
- `filter()`는 원하는 데이터만 선택하여 분석할 수 있습니다.
- `ungroup()`은 그룹을 해제하여 새로운 집계를 수행할 때 사용합니다.
- `mean()`, `sum()`, `n()`, `n_distinct()` 등 다양한 함수를 함께 활용하면 효율적인 데이터 요약이 가능합니다.

이 함수들은 **dplyr 패키지의 핵심 기능**

데이터 전처리와 탐색적 데이터 분석(EDA) 과정에서 가장 자주 사용되는 도구입니다.
