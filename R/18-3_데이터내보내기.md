# SPSS, SAS, STATA 파일로 저장하기

R에서 분석한 데이터를 다른 통계 프로그램에서 사용해야 하는 경우가 있다.

예를 들어 다음과 같은 상황에서 많이 사용된다.

- SPSS에서 통계 분석 수행
- SAS에서 대용량 데이터 분석
- STATA에서 계량경제학 분석
- 다른 연구자와 데이터 공유

이러한 파일 형식은 `haven` 패키지를 이용하여 저장할 수 있다.

---

# haven 패키지 설치

처음 사용하는 경우에는 패키지를 설치한다.

```r
install.packages("haven")
```

라이브러리를 불러온다.

```r
library(haven)
```

---

# SPSS 파일 저장하기

SPSS 파일은 `.sav` 확장자를 사용한다.

`write_sav()` 함수를 이용하여 저장할 수 있다.

```r
write_sav(
  df,
  "mtcars.sav"
)
```

현재 작업 디렉토리에

```
mtcars.sav
```

파일이 생성된다.

---

# SPSS 저장 예제

```r
student <- data.frame(

  name = c("Kim", "Lee", "Park"),

  score = c(90, 85, 95)

)

write_sav(
  student,
  "student.sav"
)
```

SPSS에서 바로 불러와 사용할 수 있다.

---

# SAS 파일 저장하기

SAS는 대용량 데이터 처리와 통계 분석에 많이 사용되는 프로그램이다.

SAS 파일은 `.sas7bdat` 확장자를 사용한다.

저장에는 `write_sas()` 함수를 이용한다.

```r
write_sas(
  df,
  "mtcars.sas7bdat"
)
```

파일이 생성되면 SAS에서 그대로 열 수 있다.

---

# SAS 저장 예제

```r
write_sas(
  iris,
  "iris.sas7bdat"
)
```

---

# STATA 파일 저장하기

STATA는 통계 분석과 계량경제학 분야에서 많이 사용하는 프로그램이다.

STATA 파일은 `.dta` 확장자를 사용한다.

```r
write_dta(
  df,
  "mtcars.dta"
)
```

---

# STATA 저장 예제

```r
write_dta(
  iris,
  "iris.dta"
)
```

# 파일 저장 시 주의사항

파일을 저장할 때 다음 사항을 확인하는 것이 좋다.

- 저장 경로가 올바른지 확인한다.
- 동일한 이름의 파일이 있는지 확인한다.
- 필요한 확장자를 사용한다.
- 작업 디렉토리를 확인한다.

예를 들어

```r

```

를 실행하면 현재 저장 위치를 확인할 수 있다.

# 저장 함수 비교

| 함수 | 저장 형식 | 확장자 |
|------|-----------|---------|
| `write.csv()` | CSV | `.csv` |
| `write.csv2()` | CSV(세미콜론 구분) | `.csv` |
| `write.table()` | Text | `.txt` |
| `write_xlsx()` | Excel | `.xlsx` |
| `saveRDS()` | R 객체 1개 | `.rds` |
| `save()` | 여러 R 객체 | `.RData` |
| `write_sav()` | SPSS | `.sav` |
| `write_sas()` | SAS | `.sas7bdat` |
| `write_dta()` | STATA | `.dta` |

---

# 어떤 형식을 사용할까?

| 상황 | 추천 형식 |
|------|-----------|
| Excel에서 열기 | Excel(.xlsx) |
| 대부분의 프로그램과 공유 | CSV(.csv) |
| R에서 다시 사용할 객체 저장 | RDS(.rds) |
| 프로젝트 전체 저장 | RData(.RData) |
| SPSS에서 분석 | SAV(.sav) |
| SAS에서 분석 | SAS7BDAT(.sas7bdat) |
| STATA에서 분석 | DTA(.dta) |

---

# 실무 팁

실무에서는 목적에 따라 저장 형식을 선택하는 것이 중요하다.

- 다른 프로그램과 공유할 때는 **CSV**를 가장 많이 사용한다.
- 보고서 작성이나 결과 전달에는 **Excel** 형식이 편리하다.
- R에서 다시 사용할 객체는 **RDS**로 저장하면 자료형과 구조를 그대로 유지할 수 있다.
- 여러 객체를 한 번에 저장하거나 프로젝트를 백업하려면 **RData**를 사용한다.
- 다른 통계 프로그램과 데이터를 주고받을 때는 **haven** 패키지의 `write_sav()`, `write_sas()`, `write_dta()` 함수를 활용한다.

---

# 자주 사용하는 함수 정리

| 함수 | 설명 |
|------|------|
| `getwd()` | 현재 작업 디렉토리 확인 |
| `setwd()` | 작업 디렉토리 변경 |
| `write.csv()` | CSV 파일 저장 |
| `write.csv2()` | 세미콜론 구분 CSV 저장 |
| `write.table()` | Text 파일 저장 |
| `write_xlsx()` | Excel 파일 저장 |
| `saveRDS()` | R 객체 하나 저장 |
| `readRDS()` | RDS 파일 읽기 |
| `save()` | 여러 객체 저장 |
| `load()` | RData 파일 읽기 |
| `write_sav()` | SPSS 파일 저장 |
| `write_sas()` | SAS 파일 저장 |
| `write_dta()` | STATA 파일 저장 |

# 정리

R에서는 다양한 형식으로 데이터를 저장할 수 있으며, 목적에 따라 적절한 파일 형식을 선택하는 것이 중요하다.

- `write.csv()`와 `write.table()`은 CSV 및 Text 파일을 저장할 때 사용한다.
- `write_xlsx()`는 Excel 파일을 저장할 때 사용한다.
- `saveRDS()`는 하나의 R 객체를 저장하며, `save()`는 여러 객체를 하나의 `.RData` 파일로 저장한다.
- `haven` 패키지의 `write_sav()`, `write_sas()`, `write_dta()`를 이용하면 SPSS, SAS, STATA 형식으로 데이터를 내보낼 수 있다.
- 저장 경로와 파일명을 올바르게 지정하면 원하는 위치에 파일을 저장할 수 있으며, 작업 목적에 맞는 파일 형식을 선택하면 다른 프로그램과의 데이터 공유도 쉽게 수행할 수 있다.
