# 상관분석(Correlation)이란?

상관분석(Correlation Analysis)은 **두 변수 사이의 관계가 얼마나 강한지**를 분석하는 통계 기법이다.

예를 들어 다음과 같은 관계를 분석할 수 있다.

- 공부 시간이 많을수록 시험 점수가 높아지는가?
- 소득이 증가하면 소비도 증가하는가?
- 광고비가 늘어나면 매출도 증가하는가?

R에서는 `cor()` 함수를 이용하여 변수 간의 상관관계를 쉽게 계산할 수 있다.

🌟가장 많이 사용하는 **피어슨(Pearson)** 과 **스피어만(Spearman)** 상관계수

---

# 상관관계의 종류

상관관계는 크게 세 가지로 구분할 수 있다.

| 상관관계 | 설명 |
|----------|------|
| 양의 상관관계(Positive Correlation) | 한 변수가 증가하면 다른 변수도 증가 |
| 음의 상관관계(Negative Correlation) | 한 변수가 증가하면 다른 변수는 감소 |
| 무상관(No Correlation) | 두 변수 사이에 일정한 관계가 없음 |

예를 들어,

- 공부 시간 ↑ → 시험 점수 ↑ → 양의 상관
- 제품 가격 ↑ → 판매량 ↓ → 음의 상관
- 혈액형과 키 → 거의 무상관

---

# 상관계수(Correlation Coefficient)

상관관계의 강도는 **상관계수(Correlation Coefficient)** 로 표현한다.

상관계수의 범위는 다음과 같다.

```text
-1 ------------------ 0 ------------------ +1
```

| 상관계수 | 의미 |
|----------|------|
| 1 | 완전한 양의 상관관계 |
| 0 | 상관관계 없음 |
| -1 | 완전한 음의 상관관계 |

일반적으로 다음과 같이 해석한다.

| 절대값(|r|) | 해석 |
|-------------|------|
| 0.0 ~ 0.2 | 거의 없음 |
| 0.2 ~ 0.4 | 약한 상관 |
| 0.4 ~ 0.6 | 보통 |
| 0.6 ~ 0.8 | 강한 상관 |
| 0.8 ~ 1.0 | 매우 강한 상관 |

※ 절대적인 기준은 아니며 분야마다 다르게 해석될 수 있다.

---

# 피어슨(Pearson) 상관계수

피어슨 상관계수(Pearson Correlation)는 가장 많이 사용하는 상관분석 방법이다.

다음과 같은 특징을 가진다.

- 연속형 변수 사용
- 선형 관계 분석
- 정규분포를 가정
- 이상치(Outlier)의 영향을 많이 받음

예를 들어

- 키와 몸무게
- 공부 시간과 시험 점수
- 광고비와 매출

등의 관계를 분석할 때 많이 사용한다.

---

# 스피어만(Spearman) 상관계수

스피어만(Spearman Correlation)은 **순위(Rank)** 를 이용하여 상관관계를 계산한다.

특징은 다음과 같다.

- 순위 기반 계산
- 정규성을 가정하지 않음
- 이상치에 강함
- 서열형(Ordinal) 데이터 분석 가능

예를 들어

- 만족도(1~5점)
- 등수
- 순위 데이터

등을 분석할 때 많이 사용된다.

---

# Pearson와 Spearman 비교

| 구분 | Pearson | Spearman |
|------|----------|-----------|
| 데이터 | 연속형 | 순위형·연속형 |
| 관계 | 선형 관계 | 단조 관계 |
| 정규성 | 필요 | 불필요 |
| 이상치 영향 | 큼 | 작음 |
| 사용 빈도 | 매우 높음 | 높음 |

---

# cor() 함수

R에서는 `cor()` 함수로 상관계수를 계산한다.

기본 문법은 다음과 같다.

```r
cor(x, y, method)
```

## 주요 인수

| 인수 | 설명 |
|------|------|
| x | 첫 번째 변수 |
| y | 두 번째 변수 |
| method | 상관계수 계산 방법 |

사용 가능한 방법은 다음과 같다.

```r
"pearson"

"spearman"

"kendall"
```

---

# 결측치가 있는 경우

데이터에 결측치(NA)가 포함되어 있다면 다음 옵션을 추가한다.

```r
cor(x,
    y,
    method = "pearson",
    use = "complete.obs")
```

`use = "complete.obs"`는 결측치가 있는 행을 제외하고 계산한다.

# 예제 데이터 불러오기

이번 예제에서는 영국 가계 소비 데이터를 사용한다.

```r
library(dplyr)

PATH <-
"https://raw.githubusercontent.com/guru99-edu/R-Programming/master/british_household.csv"

data <- read.csv(PATH)
```

---

# 데이터 전처리

먼저 이상치와 불필요한 변수를 정리한다.

```r
data1 <-
  filter(data, income < 500)
```

소득이 500 이상인 데이터를 제거한다.

다음으로 로그 변환을 수행한다.

```r
data2 <-
  mutate(
    data1,

    log_income = log(income),

    log_totexp = log(totexp),

    children_fac =
      factor(
        children,
        order = TRUE,
        labels = c("No", "Yes")
      )
  )
```

---

# 코드 설명

위 코드에서는 세 가지 작업을 수행한다.

1. 소득이 500 이상인 행 제거

```r
filter(data, income < 500)
```

2. 로그 변환

```r
log(income)

log(totexp)
```

로그 변환은

- 왜도 감소
- 이상치 영향 감소
- 분포 안정화

목적으로 자주 사용된다.

3. 자녀 수를 범주형 변수로 변환

```r
factor(children)
```

# Pearson 상관계수 계산

이제 소득과 식비의 상관관계를 계산해 보자.

```r
cor(
  data2$log_income,
  data2$wfood,
  method = "pearson"
)
```

### 결과

```text
[1] -0.2466986
```

---

# 결과 해석

상관계수는

```text
-0.2467
```

이다.

이는

- 음의 상관관계
- 강하지 않은 상관관계

를 의미한다.

즉,

**소득이 증가할수록 식비 비중은 다소 감소하는 경향**이 있다.

---

# Spearman 상관계수 계산

같은 데이터를 스피어만 방법으로 계산해 보자.

```r
cor(
  data2$log_income,
  data2$wfood,
  method = "spearman"
)
```

### 결과

```text
[1] -0.2501252
```

---

# 결과 비교

| 방법 | 상관계수 |
|------|---------:|
| Pearson | -0.2467 |
| Spearman | -0.2501 |

두 결과가 거의 비슷하므로 두 변수 사이에는 약한 음의 상관관계가 있다고 해석할 수 있다.

---

# Pearson와 Spearman는 언제 사용할까?

**Pearson를 사용하는 경우**

- 연속형 데이터
- 선형 관계 분석
- 이상치가 적은 데이터

예시

- 키와 몸무게
- 광고비와 매출
- 공부 시간과 시험 점수

---

**Spearman를 사용하는 경우**

- 순위 데이터
- 만족도 조사
- 이상치가 많은 데이터
- 정규성을 만족하지 않는 데이터

예시

- 고객 만족도
- 제품 순위
- 서비스 평가

---

# 예제 1. 양의 상관관계

```r
x <- c(1, 2, 3, 4, 5)

y <- c(2, 4, 6, 8, 10)

cor(x, y)
```

### 결과

```text
[1] 1
```

완전한 양의 상관관계이다.

---

# 예제 2. 음의 상관관계

```r
x <- c(1, 2, 3, 4, 5)

y <- c(10, 8, 6, 4, 2)

cor(x, y)
```

### 결과

```text
[1] -1
```

완전한 음의 상관관계이다.

---

# 예제 3. 상관관계가 거의 없는 경우

```r
x <- c(2, 5, 1, 8, 4)

y <- c(9, 2, 7, 3, 6)

cor(x, y)
```

### 결과(예시)

```text
[1] 0.08
```

거의 상관관계가 없다고 볼 수 있다.

# 자주 사용하는 함수 정리

| 함수 | 설명 |
|------|------|
| `cor()` | 상관계수 계산 |
| `log()` | 로그 변환 |

| `mutate()` | 새로운 변수 생성 |
| `factor()` | 범주형 변수 생성 |
| `select()` | 변수 선택 |
| `glimpse()` | 데이터 구조 확인 |

# 정리

상관분석은 두 변수 사이의 관계를 파악하는 가장 기본적인 통계 분석 방법이다.

- `cor()` 함수로 상관계수를 계산할 수 있다.
- Pearson는 연속형 데이터의 선형 관계를 분석할 때 사용한다.
- Spearman는 순위 데이터나 이상치가 많은 데이터에 적합하다.
- 상관계수는 -1에서 1 사이의 값을 가지며, 절대값이 클수록 관계가 강하다.
- 로그 변환(`log()`)은 데이터의 왜도를 줄이고 이상치의 영향을 완화하는 데 자주 사용된다.
